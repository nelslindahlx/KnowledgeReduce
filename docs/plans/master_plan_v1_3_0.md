# Master Plan — KnowledgeReduce v1.3.0

## Context & Lessons from v1.2.0
Evaluation against *Civic Honors: The Book* (`benchmarks/civichonors_book_benchmark.py`) improved **16/17** benchmark metrics with zero regressions (`core_entity_typed_recall: 0.7222 -> 1.0000`, `alias_merge_recall: 0.8000 -> 1.0000`, `heading_noise_fp_count: 12 -> 0`, `cross_type_duplicate_count: 1 -> 0`, `retrieval_hit_at_1: 0.80 -> 1.00`), leaving four concrete improvements for v1.3.0:
1. **Zero GitHub Actions Minutes & Stratified Local CI**: Move `.github/workflows/*.yml` triggers to manual `workflow_dispatch` only, add `Makefile` stratified targets (`canary`, `smoke-pr`, `local-ci`, `golden`), add `.agents/` rules + `scripts/hooks/pre_pr_safety_gate.py` + `scripts/github_pr_helper.py`, and enforce mechanical governance invariants via `tests/meta/test_governance_and_invariants.py`.
2. **Lossless Claim Clustering & Metadata-Preserving Reduction (`#23`)**: Preserve asymmetric dated facts and formal APA references in `resolve/blocking.py`, permit non-functional descriptive paraphrases to cluster, recover grounded triples & secondary provenance atomically in `reduce/reducer.py`, and de-bias structural headings across lexical+semantic retrieval in `query/graphrag.py` (`core_fact_retention`: `0.9167 -> 1.0000`, keeping `retrieval_hit_at_1 = 1.0000`).
3. **Incremental Delta Ingestion & Pre-Warmed Vector Indexing (`#24`)**: Add `incremental_from_layer` SHA-256 skip-unchanged ingestion + automatic `known_hashes` web seeding and `build_embeddings_index` pre-warming during `PipelineRunner.reduce_and_store`.
4. **Graph Analytics, Lineage & Markdown Export Surfaces (`#25`)**: Expose `list_layers`, `get_layer_lineage`, and `analyze_graph` in MCP (11 -> 14 tools) and `kr layers`, `kr lineage`, `kr analyze` in CLI, alongside `export_layer_markdown` / `render_layer_markdown` (`--format markdown`).
